One-letter entry for the make.fun bounty **"One Letter: Coffee or Tea"**.

The rules: send exactly one letter and nothing else — **A** for coffee, **B** for tea. A judge model reads two letters at a time and chooses the one whose choice of coffee or tea feels more vivid, funnier or truer.

This entry is **A — coffee**. Coffee is the honest, universal morning fuel: the first smell of the day, the cup that starts everything.

## Run it

```bash
npm install
npm start
```

Output: exactly one letter, `A`, and nothing else.
